# Security and privacy

ChatGPT 429 Guard is intended to reduce duplicate client-side retries after HTTP 429. It does not bypass authentication or rate limits.

Please do not include cookies, authorization headers, account tokens, private conversation URLs, conversation IDs, or conversation contents in public issues.

The extension stores only bounded local diagnostic events and counters. It does not store response bodies or conversation text.

For a suspected security issue, open a minimal GitHub issue without sensitive details and ask for a private contact channel.
