# ChatGPT 429 / «Не удалось загрузить этот разговор ChatGPT» — восстановление разговора

**ChatGPT Conversation Availability Guard** — название самого расширения.

Поисковые формулировки ошибки: **«Не удалось загрузить этот разговор ChatGPT»**, **«Этот чат недоступен»**, **“This chat is unavailable”**, **“Unable to load this conversation”**, **HTTP 429**, **Too Many Requests**.
Неофициальное расширение для устойчивости загрузки разговоров ChatGPT и диагностики случаев, когда из-за HTTP 429 появляется «Этот чат недоступен».

**Последний стабильный релиз:** ChatGPT Conversation Availability Guard v0.9.4.

В релизе v0.9.4:
- Добавлен **AbortSignal Multiplexing** для React 18: параллельные запросы из компонентов интерфейса разделяют единый сетевой вызов, и отмена одного компонента не срывает загрузку активного чата.
- Защита от шлюзовых сбоев Cloudflare/Envoy (**HTTP 502, 503, 504**): кратковременные тайм-ауты серверов OpenAI во время пиков теперь перехватываются и повторяются без мгновенного падения страницы в ошибку.
- Информативное уведомление (**In-DOM Toast**): если восстановление сервера занимает более 3 секунд, в углу окна появляется статус восстановления, исключая ощущение «зависшей страницы».
- Точечный cooldown при отмене: отмена запроса пользователем изолирует задержку только на отменённом чате, не блокируя остальные вкладки на 12 секунд.
- Официальные иконки всех размеров (16, 32, 48, 128 px) и автоматизированная сборка релизного ZIP-архива для Chrome Web Store (`npm run pack`).

Расширение **не обходит лимиты OpenAI и не увеличивает лимиты подписки**. Оно уменьшает лишний retry-storm, соблюдает Retry-After и удерживает безопасный GET до восстановления сервера в ограниченном временном окне.

## Что v0.9.4 защищает активно

Автоматические retry/dedupe применяются только к безопасным GET:

- GET /backend-api/conversations/{id}
- GET /backend-api/conversation/{id}
- GET /backend-api/conversation/{id}/stream_status
- GET /backend-api/conversations

Связанные POST:

- POST /backend-api/f/conversation/resume
- POST /backend-api/conversations/batch
- POST /backend-api/conversation/init

только наблюдаются. Автоматически повторять их нельзя, пока не доказана идемпотентность: иначе можно задублировать действие.

Отправка сообщений, загрузка файлов, модельные запросы и другой несвязанный трафик не меняются.

## Диагностика

Popup теперь хранит и копирует ограниченную историю последних безопасных событий. Для каждого сбоя важны:

- поверхность: conversation-detail, stream-status, conversation-resume и т. п.;
- HTTP method/status;
- была ли защита active или запрос только наблюдался;
- попытка, задержка и Retry-After, если они есть;
- время события.

В storage/экспорт не должны попадать текст разговоров, cookies, Authorization, body запросов/ответов, полный URL, ID разговора, tab ID или correlation hash.

Если «Этот чат недоступен» повторится, лучше сразу нажать **Copy safe diagnostics** до долгого дальнейшего использования вкладки.

## Проверенные локальные сценарии v0.9.4

В deterministic Playwright-тесте (29 из 29 тестов пройдены):

- мультиплексирование AbortSignal при параллельных рендерах React 18;
- восстановление при шлюзовых 504 Gateway Timeout от Cloudflare;
- 5 одновременных одинаковых запросов схлопываются в один сетевой вызов;
- stream_status и conversation-detail безопасно восстанавливаются при 429;
- POST resume/batch/init при 429 выполняются только один раз;
- privacy-check подтверждает отсутствие приватных идентификаторов в сохранённых событиях.

## Установка и сборка

Для использования:

1. Скачайте ZIP (`chatgpt-conversation-availability-guard-v0.9.4.zip`) из Releases (или соберите командой `npm run pack`).
2. Распакуйте архив в постоянную папку.
3. Откройте `chrome://extensions`.
4. Включите «Режим разработчика».
5. Нажмите «Загрузить распакованное расширение».
6. Выберите папку `extension`.
7. Перезагрузите открытые вкладки ChatGPT.

Руководство для публикации в интернет-магазине Chrome и материалы для продвижения:
- [Руководство по публикации в Chrome Web Store](docs/CHROME_STORE_LISTING.md)

## Ветки

- main — опубликованное стабильное состояние;
- 429-only — узкая ветка восстановления HTTP 429;
- maintenance/investigation branches — проверка следующих изменений.

GitHub-репозиторий называется **chatgpt-429-conversation-recovery**: в названии намеренно есть ChatGPT, 429 и conversation recovery, чтобы проект находился по самой ошибке. Название установленного расширения остаётся **ChatGPT Conversation Availability Guard**.

Проект неофициальный и не связан с OpenAI.
