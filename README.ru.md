# ChatGPT Stream Recovery

Публичный проект для точечных исправлений сбоев ChatGPT, связанных с загрузкой разговоров и восстановлением стрима.

Сейчас стабильная версия — **ChatGPT 429 Guard v0.8.0**. Она не обходит ограничения OpenAI и не увеличивает лимиты. Расширение только не даёт клиенту бессмысленно повторять одинаковые запросы после HTTP 429 и соблюдает паузу перед следующей попыткой.

## Что защищается

Расширение вмешивается только в чтение разговоров:

- `GET /backend-api/conversations/{id}`
- `GET /backend-api/conversation/{id}`
- `GET /backend-api/conversations`

Отправка сообщений, загрузка файлов, обращения к моделям и POST-запросы разговоров не меняются.

## Установка

1. Скачайте ZIP последнего релиза.
2. Распакуйте его в постоянную папку.
3. Откройте `chrome://extensions`.
4. Включите «Режим разработчика».
5. Нажмите «Загрузить распакованное расширение».
6. Выберите папку `extension`.
7. Перезагрузите вкладки ChatGPT.

В окне расширения есть кнопка **Copy safe diagnostics**. Она копирует только технические счётчики — без текста разговоров, cookies, тел ответов, полных URL и ID разговоров.

## Ветки

- `main` — основная стабильная версия проекта.
- `429-only` — ветка только для борьбы с HTTP 429.
- Другие типы сбоев будут разрабатываться отдельно и не попадут в стабильную 429-логику без проверки.

Проект неофициальный и не связан с OpenAI.
