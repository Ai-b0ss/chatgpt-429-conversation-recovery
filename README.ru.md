# ChatGPT Stream Recovery — «Этот чат недоступен», HTTP 429 и обрывы загрузки

Публичный проект для точечных исправлений сбоев ChatGPT, связанных с загрузкой разговоров и восстановлением стрима.

Если ChatGPT показывает плашку **«Этот чат недоступен»**, разговор перестаёт загружаться, стрим обрывается или в сети идут ответы **HTTP 429 / Too Many Requests**, этот репозиторий предназначен именно для исследования и исправления таких случаев.

Сейчас стабильная версия — **ChatGPT 429 Guard v0.9.0**. Она сохраняет весь проверенный 429-контур v0.8.4 и добавляет ограниченное восстановление отдельной ошибки потерянного стрима: ChatGPT недавно сообщил `IS_STREAMING`, штатный `POST /backend-api/f/conversation/resume` вернул 404, а естественное завершение не пришло. Guard повторяет только уже наблюдавшийся штатный resume-запрос с ограниченными offsets, проверяет восстановленный SSE перед подменой 404 и подчиняется тому же общему kill switch.

Важно: сама плашка «Этот чат недоступен» всё ещё может появляться и по другим причинам. v0.9.0 покрывает проверенный путь conversation-read 429 и отдельный проверенный путь resume-404/lost-stream; остальные причины остаются вне stable до отдельной проверки.

## Что защищается

Основной 429-контур вмешивается только в чтение разговоров:

- `GET /backend-api/conversations/{id}`
- `GET /backend-api/conversation/{id}`
- `GET /backend-api/conversations`

Отдельно v0.9.0 может повторить штатный `POST /backend-api/f/conversation/resume`, но только если этот же запрос ChatGPT уже вернул 404 и для того же разговора есть свежее штатное `IS_STREAMING`. Повторяется исходный Request с теми же headers/credentials; меняется только ограниченный `offset`.

Отправка новых сообщений, загрузка файлов, обращения к моделям и запуск новых генераций не меняются.

## Установка

1. Скачайте ZIP последнего релиза.
2. Распакуйте его в постоянную папку.
3. Откройте `chrome://extensions`.
4. Включите «Режим разработчика».
5. Нажмите «Загрузить распакованное расширение».
6. Выберите папку `extension`.
7. Перезагрузите вкладки ChatGPT.

В окне расширения есть кнопка **Copy safe diagnostics**. Она копирует только технические счётчики — без текста разговоров, cookies, тел ответов, полных URL и ID разговоров.

## Ветки

- `main` — текущая стабильная объединённая версия.
- `429-only` — узкая ветка, оставленная только для проверенного HTTP 429-контура.
- новые типы сбоев по-прежнему проходят отдельную ветку, regression и live canary до слияния в stable.

Проект неофициальный и не связан с OpenAI.
